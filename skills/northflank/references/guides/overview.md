### How-to guides

Start with a [use-case guide](use-cases.md#choose-a-use-case) when your task involves several features. Each guide explains the order and links to the configuration instructions.

| Task | Guide |
| --- | --- |
| Prepare a web application and database | [Deploy a production app](use-cases.md#deploy-a-production-app) |
| Process work outside a web request | [Run background tasks](use-cases.md#run-background-tasks) |
| Use GPU compute | [Run GPU workloads](use-cases.md#run-gpu-workloads) |
| Test pull requests in separate environments | [Create preview environments](use-cases.md#create-preview-environments) |
| Access external cloud resources | [Connect an app to AWS](use-cases.md#connect-an-app-to-aws) |

To configure a known feature, open its sidebar section. Compute → GPUs contains GPU configuration. Services contains scaling and health checks. Networking contains domains and TLS. Cloud integrations contains provider links, workload identities, and external resources. Cloud → Bring your own cloud contains BYOC and BYOK setup.

[API & tools](../api/introduction.md) covers API access, the CLI, and the JavaScript client.
