# Pause preview environment

Source: https://northflank.com/docs/v1/api/project/preview-blueprints/pause-preview-environment.md

Pause a preview environment generated by a preview blueprint.

Required permission: Project > PipelinesV2 > Previews > Pause

**Path parameters:**

{object}
- `projectId`: (string) (required) ID of the project
- `previewBlueprintId`: (string) (required) ID of the preview blueprint
- `previewId`: (string) (required) ID of the preview

**Response body:**

{object}
- `data`: {object}

### API reference

POST /v1/projects/{projectId}/preview-blueprints/{previewBlueprintId}/previews/{previewId}/pause

POST /v1/teams/{teamId}/projects/{projectId}/preview-blueprints/{previewBlueprintId}/previews/{previewId}/pause

#### Example Response

200 OK: The operation was performed successfully.

```json
{
  "data": {}
}
```

### CLI reference

$ northflank pause blueprint-template-preview

Options:

- `--projectId <projectId>`: ID of the project

- `--previewBlueprintId <previewBlueprintId>`: ID of the preview blueprint

- `--previewId <previewId>`: ID of the preview

- `--verbose `: Verbose output

- `--quiet `: No console output

- `-o --output <format>`: Output formatting

### Python client reference

#### Example request

[Set up the Python client](../../use-the-python-client.md#usage).

With an organization token, add `team_id`. [Organization API access](../../use-the-api.md#organization-api-access).

```python
from northflank import ApiClient

# Reads NORTHFLANK_API_TOKEN or NF_API_TOKEN
client = ApiClient()

response = client.pause.blueprint_template_preview(
    preview_blueprint_id="development",
    preview_id="example-preview",
    project_id="default-project",
)
print(response.data)
```
